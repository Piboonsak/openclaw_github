# Contributing

ขอบคุณที่สนใจพัฒนา AI Pre-Accounting Copilot 🎉

## Development Setup
1. Create and activate virtual environment
2. Install dependencies from `requirements.txt`
3. Copy `.env` from `config/.env.example`

## Coding Guidelines
- Keep changes focused and small
- Add or update tests when behavior changes
- Avoid committing customer data, credentials, or API keys

## Pull Request Checklist
- [ ] Code is clear and minimal
- [ ] Relevant tests pass
- [ ] No secrets or private data committed
- [ ] Docs updated when behavior/config changes
