High-Level Infra Network Design (Customer Version)

เอกสารนี้อธิบายภาพรวมโครงสร้างระบบแบบเข้าใจง่าย: WebApp อยู่บน Cloud, พนักงานบัญชี/Manager/Owner ใช้ PC ของตัวเองเข้าใช้งานผ่าน HTTPS, และนำผลลัพธ์ CSV เข้า Express Account ที่ติดตั้งบน Server On-Prem ในสำนักงาน

1) Network Overview

HTTPS ผู้ใช้งานทุกบทบาทเข้าหน้า WebApp ผ่าน Browser แบบเข้ารหัส

Cloud Components User / On-Prem Download CSV Path Manual CSV Path Auto Export Path (Optional)

2) End-to-End Data Flow

1. Accountant เปิดเอกสารใน PC ตัวเอง (PDF/JPG/PNG) แล้วอัปโหลดผ่านหน้าเว็บ
2. Cloud ประมวลผล OCR + จัดประเภทเอกสาร + แนะนำบัญชี
3. Accountant ตรวจข้อมูล, Manager ตรวจความถูกต้อง, Owner ติดตามภาพรวม
4. ระบบสร้างไฟล์ผลลัพธ์ CSV ตามรูปแบบ Express GL
5. CSV ถูกนำเข้า Express Account บนเซิร์ฟเวอร์สำนักงาน

3) User Roles

Accountant

  • อัปโหลดเอกสารจากเครื่องตัวเอง
  • Review Scan + Mapping
  • Export CSV

Manager

  • ติดตามงานคงค้าง
  • ตรวจ mismatch และคุณภาพข้อมูล
  • อนุมัติใน workflow

Owner

  • ดู dashboard ภาพรวม
  • ติดตามสถานะ export
  • เห็นแนวโน้มผลลัพธ์ธุรกิจ

4) CSV Transfer เข้า Express (2 ทางเลือก)

Mode A: Manual ดาวน์โหลด CSV แล้วนำเข้าโดยผู้ใช้งาน

Mode B: Assisted Auto Sync มี service ฝั่งสำนักงานรับไฟล์และรัน import job อัตโนมัติ

  • แนะนำเริ่มจาก Manual เพื่อ go-live ได้เร็ว
  • เมื่อระบบนิ่ง ค่อยเพิ่ม Auto Sync เพื่อลดงานมือ

5) Security Summary

  • ทุกการใช้งานผ่าน HTTPS/TLS
  • แยกสิทธิ์ตามบทบาท (Accountant/Manager/Owner)
  • เก็บ Audit Trail: upload, edit, approve, export, import
  • สำหรับ Auto Sync ควรใช้ VPN หรือ IP allowlist ตามนโยบาย IT
