เงื่อนไขทั่วไป

  1. ใบเสนอราคานี้มีผลบังคับ 30 วัน นับจากวันที่ออก หากเกินกำหนดดังกล่าว ผู้รับจ้างขอสงวนสิทธิ์ในการปรับราคาตามความเหมาะสม
  2. ขอบเขตงาน: รายละเอียดขอบเขตงาน ผลส่งมอบ ข้อจำกัด และเงื่อนไขอื่นๆ เป็นไปตามสัญญาจ้างพัฒนาซอฟต์แวร์ Phase II Combined Package (เอกสารแนบ) ใบเสนอราคานี้เป็นเอกสารประกอบสัญญา ไม่ใช่สัญญาในตัวเอง
  3. ราคายังไม่รวม VAT: หากผู้รับจ้างมีสถานะจดทะเบียน VAT จะเรียกเก็บ VAT เพิ่มเติมตามอัตราที่กฎหมายกำหนด
  4. Change Request (CR): งานที่อยู่นอกขอบเขตสัญญาจะคิดค่าบริการในอัตรา 20,000–30,000 บาท/man-day ตามความยากง่าย โดยต้องได้รับอนุมัติจากผู้ว่าจ้างก่อนเริ่มงาน
  5. ความรับผิดชอบของผู้ว่าจ้าง: ผู้ว่าจ้างต้องจัดส่ง (ก) ตัวอย่าง CSV/Excel ที่ import เข้า Express ได้จริง (ข) ผังบัญชี COA (ค) รายชื่อผู้จำหน่ายและรายชื่อลูกค้า (ง) ตัวอย่างเอกสารสำหรับ OCR testing (จ) ข้อมูล DNS/hosting ที่จำเป็น ทั้งนี้ภายในระยะเวลาที่ตกลงร่วมกัน
  6. ข้อจำกัดด้าน AI/OCR: ระบบนี้เป็นเครื่องมือช่วยจัดเตรียมข้อมูล (Pre-Accounting) ไม่ใช่ระบบบัญชีเต็มรูปแบบ ผู้ใช้ต้องตรวจสอบข้อมูลก่อน export ทุกครั้ง
  7. ทรัพย์สินทางปัญญา: เป็นไปตามข้อกำหนดในสัญญาจ้างพัฒนาซอฟต์แวร์ Phase II
