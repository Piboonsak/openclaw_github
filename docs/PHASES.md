# Project Phases

## PoC Phase (1-2 สัปดาห์)
**Goal:** Validate OCR + extraction quality on representative accounting documents.

Scope:
- Define target document types
- Build OCR and field extraction prototype
- Measure baseline accuracy and error categories

Deliverables:
- PoC demo flow
- Initial accuracy report
- Risk and feasibility assessment

## MVP Phase (4-6 สัปดาห์)
**Goal:** Deliver API-ready workflow with validation rules and operational readiness.

Scope:
- Stabilize extraction schema
- Add validation and exception handling
- Expose API endpoints for processing and health checks
- Prepare deployment and monitoring baseline

Deliverables:
- MVP API workflow
- Documentation and runbook
- UAT-ready version
