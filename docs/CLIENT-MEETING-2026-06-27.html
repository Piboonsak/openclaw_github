5 · เราเข้าใจ Requirement ของคุณ — ยืนยันอีกครั้ง
ถ้าพี่มี list รายชื่อผู้จำหน่าย, รายชื่อลูกค้า เข้าไปในระบบ, ai สามารถตรวจเช็คและเลือก รหัสผู้จำหน่าย หรือ รหัส ลูกหนี้ ขึ้นมาใส่ให้ได้เองไหมคะ กรณีที่มีเจ้าหนี้ หรือ ลูกหนี้รายใหม่ เพิ่มเข้ามา
✅ เข้าใจแล้ว — BL-001 (ออกแบบ schema W2, matching W3-W4)
ขั้นตอนที่ระบบจะทำ:
Import CSV → vendor_master DB → OCR อ่านชื่อ → Match 3 ระดับ → แสดง suggestion → User confirm → Cache ไว้ครั้งต่อไป
3 ระดับ matching: Exact → Fuzzy ≥ 85% → AI ช่วย 70–84%

vendor_code รองรับทุก format จาก Express: ตัวเลขล้วน (1–8888), S-0001, 1220-01 (เก็บเป็น VARCHAR)
rหัส GL (2120-01, 2131-09) ดึงมาพร้อม vendor record โดยตรง — AI ไม่ต้องเดา
ลูกค้าใหม่ที่ match ไม่ได้: ระบบ flag ให้ user สร้าง record ใหม่ (pre-fill จาก OCR)
ต้องการสร้าง description แบบรวมข้อมูลหลายฟิลด์ เช่น {seller_name} {expense_type} เพื่อให้เห็นทั้งชื่อผู้ขายและประเภทค่าใช้จ่ายในคอลัมน์เดียว
✅ เข้าใจแล้ว — BL-007 · concat transform (ทำใน W3 TASK-1001)
Template column definition จะรองรับ:
"transform": "concat:seller_name,expense_type"
ผลลัพธ์: "บริษัท ABC จำกัด ค่าเช่า" ในคอลัมน์ description คอลัมน์เดียว
Config ตัว separator ได้ (space, " | ", " - ")
ต้องการกรองแถวที่ไม่ต้องการออกจาก CSV โดยเฉพาะรายการ VAT ซื้อ (1151) และเจ้าหนี้การค้า (2110) เพราะ Express จัดการเองอัตโนมัติ
✅ เข้าใจแล้ว — BL-008 · row filter config (ทำใน W3 TASK-1001)
แต่ละ template จะมี config ว่า COA codes ไหน ไม่ต้องส่ง ไปใน CSV:
exclude_account_codes: ["1151", "2110"]
ระบบ filter หลัง AI map COA แต่ ก่อน write CSV — แต่ละ template filter ต่างกันได้

⚠️ ต้องยืนยันกับลูกค้า: แถว 1151 ยังต้องไปอยู่ใน รายงานภาษีซื้อ (ภ.พ.30) ไหม? ถ้าใช่ จะใช้ filter แยกตาม template
วันที่ใน CSV ที่เปิดใน Excel แล้วกลายเป็น DD/MM/YYYY ทั้งที่ต้องการแค่ DD/MM/YY (2 หลัก พ.ศ.)
✅ แก้แล้ว — BL-002 → รวมใน TASK-1001 (W3)
Root cause: Excel auto-convert date string → date value แล้ว reformat
Fix: เขียน date เป็น plain text string (ไม่ใช่ date cell) ใน CSV และ Excel
thai_date_short: 2026-05-01 → "01/05/69" (text, ไม่ถูก Excel แปลง)
ระบบอ่านรายการสินค้าแต่ละบรรทัดในใบแจ้งหนี้ได้ไหม? (Line Item Extraction)
