วิธีอัปโหลดทีละขั้น

  1. เลือกชื่อบริษัท ①คลิก Dropdown แล้วเลือกกิจการที่ต้องการ หากยังไม่มีให้เพิ่มผ่านเมนู ⚙ Settings ก่อน
  2. นำเข้าไฟล์ ②ลากไฟล์วางใน Drop Zone หรือคลิกเปิด File Browser — PDF, JPG, PNG ไม่เกิน 50 MB ต่อไฟล์
  3. ตรวจสถานะ Tax ID ③④ไฟล์ที่ Tax ID ตรงแสดง ✓ สีเขียว ไม่ตรงแสดง ⚠ สีเหลือง ต้องจัดการก่อนดำเนินต่อ
  4. กด "Continue →"เมื่อรายการไฟล์ครบถ้วน กดดำเนินต่อ

คำถามที่พบบ่อย (FAQ)

AI อ่านตัวเลขผิด เช่น 10,000 เป็น 100,000 ทำอย่างไร?
แก้ไขได้ทันทีในขั้นตอนที่ 4 คลิกที่ฟิลด์ยอดเงินและพิมพ์ค่าที่ถูกต้อง ระบบจะคำนวณ VAT, WHT และ Gross ใหม่อัตโนมัติ
ระบบแนะนำรหัสบัญชีผิด เช่น บัญชีค่าเช่าถูกจัดเป็นค่าใช้จ่ายทั่วไป ทำอย่างไร?
ในขั้นตอนที่ 5 ให้คลิก Dropdown ที่บรรทัดนั้น พิมพ์ชื่อหรือรหัสบัญชีที่ถูกต้องแล้วเลือก กด Confirm — ครั้งต่อไประบบจะแนะนำรหัสที่ถูกต้องสำหรับซัพพลายเออร์รายนี้โดยอัตโนมัติ
อัปโหลดเอกสารข้ามบริษัทได้ไหม?
ต้องแยกทำทีละบริษัท เลือกบริษัท A ทำให้เสร็จก่อน Export แล้วค่อยกลับมาเลือกบริษัท B ป้องกันการปนเอกสารข้ามกิจการ
ไฟล์ PDF ภาพไม่ชัด ระบบอ่านไม่ออก ทำอย่างไร?
ระบบแสดง ❌ Error ในคอลัมน์ OCR แนะนำสแกนใหม่ที่ความละเอียด ≥ 300 DPI หรือถ่ายรูปในที่แสงสว่างพอ หลีกเลี่ยงภาพเบลอหรือหน้ากระดาษโค้ง
ต้องเพิ่มบริษัทใหม่ในระบบ ทำอย่างไร?
คลิกไอคอน ⚙ (Settings) มุมขวาบน เลือก "Company & COA Settings" แล้วกด "+ Add Company" กรอกชื่อบริษัทและ Tax ID 13 หลัก กด Save — บริษัทจะปรากฏใน Dropdown ขั้นตอนที่ 1 ทันที
Export แล้ว Import ไม่เข้า Express — บอกว่า "รหัสบัญชีไม่พบ"
รหัสบัญชีในไฟล์ CSV ไม่ตรงกับที่ตั้งใน Express ตรวจ 2 จุด: (1) ผังบัญชีใน Settings ของ LedgerFlow ตรงกับที่ตั้งใน Express หรือไม่ (2) รหัสที่แก้ไขในขั้น 5 ถูกต้องครบถ้วนหรือไม่
VAT ที่ดึงมาเป็น "ภาษีซื้อ" หรือ "ภาษีขาย"?
พิจารณาจากประเภทเอกสาร: รับใบกำกับจากซัพพลายเออร์ (เราเป็น Buyer) → VAT คือ "ภาษีซื้อ" (Dr 1152). ออกใบกำกับให้ลูกค้า (เราเป็น Seller) → VAT คือ "ภาษีขาย" (Cr 2151). ตรวจสอบจาก Tax ID ผู้ขาย/ผู้ซื้อในขั้นตอนที่ 4
