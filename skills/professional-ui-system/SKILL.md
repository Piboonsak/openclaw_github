# Skill: Professional UI System

## Purpose
Produce high-quality accounting UI with clear hierarchy, consistency, and strong usability.

## When to Use This Skill
- Building or refactoring Step 5/Step 6 interfaces
- Adding export configuration and journal mapping flows
- Improving perceived quality from prototype to production

## Step-by-Step Workflows
- Typography scale and spacing tokens are explicit
- Form controls have error, loading, and success states
- Desktop/mobile behavior is verified
- Accessibility basics: keyboard flow, labels, contrast

## Output Checklist
- Component structure plan
- UI behavior matrix
- Interaction tests and edge-case coverage
